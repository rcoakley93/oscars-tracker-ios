# Oscars Tracker for iOS

Track the Academy Awards nominees, plan your watching, make your picks and beat your friends on Oscar night. A native SwiftUI app for iPhone, iPhone Duo and iPad, iOS 26 and later.

- **Season plan, database and website:** the backend repo, `rcoakley93/oscars-tracker` (`docs/season-2027/`).
- **Working on the app:** see [AGENTS.md](AGENTS.md) for the project layout, build and test commands, and conventions.
