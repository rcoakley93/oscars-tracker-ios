# Ralph Progress Log

## Codebase Patterns
- Xcode project structure: OscarsTracker/OscarsTracker.xcodeproj with source files in OscarsTracker/OscarsTracker/
- Data models: Use Codable + Identifiable protocols, CodingKeys for snake_case to camelCase mapping
- SwiftUI lifecycle: Use @main attribute on App struct
- Swift Package Manager: Dependencies added in project.pbxproj with XCRemoteSwiftPackageReference
- iOS 17+: Target IPHONEOS_DEPLOYMENT_TARGET = 17.0
- Playwright tests: Can validate iOS project structure via filesystem checks
- Components: Place in OscarsTracker/OscarsTracker/Components/ folder
- ViewModifiers: Implement as struct conforming to ViewModifier, add extension on View for convenience
- ButtonStyles: Implement as struct conforming to ButtonStyle with makeBody(configuration:)
- Glow effects: Use multiple stacked shadows with varying radii and opacities
- ViewModels: Place in OscarsTracker/OscarsTracker/ViewModels/ folder, use @MainActor + ObservableObject
- Views: Organize by feature (e.g., Views/Auth/) with subfolders
- Auth: Use Supabase Auth with signIn(email:password:), wrap in Task for async
- TextFieldStyle: Create custom styles with _body(configuration:) for consistent input styling
- Supabase Insert: Use [String: AnyJSON] dict with .string(), .integer() etc for dynamic values
- FAB Pattern: ZStack(alignment: .bottomTrailing), add .padding(.bottom, 80) to ScrollView content
- Sheet with Item: .sheet(item: $optionalItem) auto-dismisses when binding set to nil
- Supabase Update: .update(["field": value]).eq("id", value: id) for updating specific fields
