# Ralph Progress Log

## Codebase Patterns
- Xcode project structure: OscarsTracker/OscarsTracker.xcodeproj with source files in OscarsTracker/OscarsTracker/
- Data models: Use Codable + Identifiable protocols, CodingKeys for snake_case to camelCase mapping
- SwiftUI lifecycle: Use @main attribute on App struct
- Swift Package Manager: Dependencies added in project.pbxproj with XCRemoteSwiftPackageReference
- iOS 17+: Target IPHONEOS_DEPLOYMENT_TARGET = 17.0
- Playwright tests: Can validate iOS project structure via filesystem checks
- Components: Place in OscarsTracker/OscarsTracker/Components/ folder
- ViewModifiers: Implement as struct conforming to ViewModifier, add extension on View for convenience
- ButtonStyles: Implement as struct conforming to ButtonStyle with makeBody(configuration:)
- Glow effects: Use multiple stacked shadows with varying radii and opacities
- ViewModels: Place in OscarsTracker/OscarsTracker/ViewModels/ folder, use @MainActor + ObservableObject
- Views: Organize by feature (e.g., Views/Auth/) with subfolders
- Auth: Use Supabase Auth with signIn(email:password:), wrap in Task for async
- TextFieldStyle: Create custom styles with _body(configuration:) for consistent input styling
- Supabase Insert: Use [String: AnyJSON] dict with .string(), .integer() etc for dynamic values
- FAB Pattern: ZStack(alignment: .bottomTrailing), add .padding(.bottom, 80) to ScrollView content
- Sheet with Item: .sheet(item: $optionalItem) auto-dismisses when binding set to nil
- Supabase Update: .update(["field": value]).eq("id", value: id) for updating specific fields
- Supabase Delete: .delete().eq("id", value: id) for removing records
- Alert with Data: .alert(presenting: $optionalItem) for alerts with associated value
- iPad Grid: Use horizontalSizeClass == .regular with LazyVGrid for 2-col on iPad, 1-col on iPhone
- Expandable Card: @State isExpanded with toggle, animate with .easeInOut, use chevron icon
- Supabase Upsert: .upsert(data, onConflict: "col1,col2") for composite unique constraints
- Radio Button: Circle().stroke() + Circle().fill() for filled radio indicator
- Selection State: Dictionary<Int, Int> for parent-to-child ID mapping (e.g., categoryId -> nominationId)
- Timer Pattern: Timer.scheduledTimer(withTimeInterval: 1, repeats: true) with onAppear/onDisappear lifecycle
- Time Calculations: days = secs/86400, hours = (secs%86400)/3600, mins = (secs%3600)/60
- Monospaced Digits: .font(.system(size:, weight:, design: .monospaced)) for countdowns
- Supabase RPC: .rpc("function_name").execute().value for database function calls
- Conditional Styling: enum for style variants (MedalType.gold/silver/bronze)
- OAuth: ASWebAuthenticationSession with callback URL scheme, getOAuthSignInURL() then session(from:)
- OAuth Provider: Use WebAuthPresentationContextProvider conforming to ASWebAuthenticationPresentationContextProviding
- Async Bridge: withCheckedThrowingContinuation to convert callback APIs to async/await
- Sheet Detents: Use .presentationDetents([.large]) for sheets with graphical DatePicker
- Sheet Animation: @State isAppeared with .onAppear + withAnimation for smooth open transition
- Prevent Accidental Dismiss: interactiveDismissDisabled(isLoading) during async operations
- Drag and Drop: Use CodableRepresentation(contentType: .data) instead of custom UTType
- Drag Hit Testing: Add .contentShape(Rectangle()) for proper drag recognition area
